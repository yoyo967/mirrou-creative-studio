## 02 · Unser Ansatz

Mirrou arbeitet nicht mit einzelnen Bildlieferungen. Wir bauen eine **Creative Engine** — ein System, das kontinuierlich performende Assets produziert, testet und verbessert.

**Der 5-Schritt-Algorithmus:**

1. **Diagnose** → Creative Audit: CTR, CPC, Fatigue-Analyse *(bereits abgeschlossen)*
2. **Hypothesen** → 3 testbare Annahmen aus euren Daten
3. **Execution** → Hybrid Production: High-End-Fotografie + KI-Elemente
4. **Testing** → A/B-Struktur mit min. 3 Varianten je Hypothese
5. **Loop** → Learning Log → nächste Hypothesen → nächste Produktion
