    If-this-then-that: Regeln für autonome Phase 3

    Budget-Regeln

    IF CTR steigt + CPC fällt für 3+ Tage THEN Scale Budget +20% auf Winner-Creative
    IF CPA > €70 für 3+ Tage THEN Pause Ad-Set, Creative überarbeiten, Audience neu testen
    IF ROAS > 2.5 für 5+ Tage THEN Budget +30%, auf neue Kanäle expandieren
    IF ROAS < 1.5 für 3+ Tage THEN Kill Campaign, Budget auf Winner umverteilen
    IF Thumb-Stop > 30% + View-Rate > 45% THEN Creative als Template für neue Varianten

    Creative-Regeln

    IF CTR < 1% für 5+ Tage THEN Kill Creative, Hook-Generator neu starten
    IF Engagement > 5% + Shares > 1% THEN Scale auf Lookalike-Audience
    IF Landing-Page-Depth < 40% THEN Hero-Section überarbeiten vor Budget-Erhöhung
    IF Download-Rate > 5% + Call-Booking < 3% THEN Nurture-Sequenz optimieren, CTA stärken
    IF Email-Open < 25% nach 2 Sends THEN Subject-Line-Test, Sender-Name-Test

    Launch-Path für Phase 3

    Phase 3A: Fiktive Cases (Tag 26–40)

    Luminous Aura, Vitality Pulse etc. als Proof-Systeme nutzen. Validierung von Creative, Funnel und AI-Workflows bei minimalem Risiko. Budget: €3.000.

    Phase 3B: Pilot-Kunden (Tag 41–60)

    Erste echte Kunden aus Zielgruppe (Beauty/Health/Lifestyle). Reduzierter Preis, volles Service-Paket. Ziel: 2–3 Pilot-Projekte. Budget: €5.000.

    Phase 3C: Full Scale (Tag 61+)

    Volles Budget, alle Kanäle, alle AI-Agenten autonom. Ziel: 5+ Kunden, €15K+ MRR. Budget: €10.000+/Monat.
