# Inbound-Strategie – Mirrou Creative Studio

> Yahyas Kernverantwortung: Growth & Inbound. Dieses Dokument definiert, wie Mirrou qualifizierte Leads anzieht — ohne kalte Massenwerbung, mit einem System das sich selbst verstärkt.

---

## Inbound-Philosophie

Mirrou spricht Kunden nicht an. **Mirrou zieht sie an** — durch Kompetenz-Beweis, nicht durch Versprechen.

```
KLASSISCHE AGENTUR          MIRROU INBOUND
Kaltakquise → Pitch         Kontext → Vertrauen → Anfrage
„Wir sind die Besten"       „Hier ist der Beweis"
Breit streuen               Präzise anziehen
```

**Kern-Annahme**: Ein D2C-Brand-Founder, der Creative Fatigue erlebt, sucht aktiv nach Lösungen. Mirrou muss dort sein, wenn er sucht — und glaubwürdig sein, wenn er landet.

## KANAL 1 · mirrou.studio (Konversions-Hub)

### Ziel
Website ist nicht Visitenkarte — sie ist **Lead-Qualifizierungs-Maschine**.

### Architektur-Prinzipien (Yahya-Verantwortung)

| Element | Funktion |
|---------|---------|
| **Hero-Section** | Sofortiger Kompetenz-Beweis: Claim + Case-Zahlen |
| **Case Studies** | Vertrauen durch Ergebnis-Beweis (CTR +82 %, CPC −38 %) |
| **Services** | Klare Pakete mit Preisen → kein Raten, kein Nachfragen |
| **Trust Center** | EU AI Act-Compliance offen kommuniziert |
| **Kontaktformular** | Ad-Spend-Segmentierung → qualifiziert Lead automatisch |
| **Brandbook** | Ästhetik-Beweis für qualitätsbewusste Founder |

### Kontaktformular-Felder (Qualifizierung)
```
1. Name + E-Mail (Pflicht)
2. Brand-Name (Pflicht)
3. Monatlicher Ad-Spend:
   ☐ < 5.000 €  ☐ 5.000–20.000 €  ☐ 20.000–50.000 €  ☐ > 50.000 €
4. Primärer Kanal: ☐ Meta ☐ TikTok ☐ Beide ☐ Andere
5. Größte aktuelle Herausforderung (Freitext)
6. Wie habt ihr von uns gehört?
```

**Interne Regel**: Leads mit > 20.000 € Ad-Spend werden innerhalb von 4h beantwortet.

## Inbound-Funnel (vollständig)

```
AWARENESS
Instagram / LinkedIn / TikTok → Mirrou wird sichtbar
        ↓
INTEREST
Profil-Besuch → mirrou.studio → Case Studies, Trust Center
        ↓
CONSIDERATION
Services-Seite → Preise → Kontaktformular ausfüllen
        ↓
QUALIFIZIERUNG
Ad-Spend-Segmentierung im Formular → automatische Priorisierung
        ↓
CONVERSION
30-Min-Strategiegespräch (Yahya) → Creative Audit → Angebot
        ↓
RETENTION
Retainer-System → Learning Log → Data Feedback Loop
```
