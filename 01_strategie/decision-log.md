# Entscheidungslog – Mirrou Creative Studio · Abschlussarbeit

> Lebendiges Dokument. Jede wichtige Projekt-Entscheidung wird hier festgehalten — mit Datum, Alternativen und Begründung. Ermöglicht Nachvollziehbarkeit für Präsentation und Prüfung.

---

## Format

```
### [DATUM] · [Entscheidung in einem Satz]
**Alternativen geprüft**: Was wurde sonst erwogen?
**Entscheidung**: Was wurde gewählt?
**Begründung**: Warum?
**Entschieden von**: Wer?
```

---

## Strategische Entscheidungen

### 2026-05 · Positionierung: Nische statt Generalist
**Alternativen geprüft**: Full-Service Agentur für alle Branchen / Social Media Agentur
**Entscheidung**: Spezialisierung auf D2C Beauty/Health/Lifestyle — DACH-Markt
**Begründung**: Creative Fatigue ist das präzise Problem dieser Nische. Spezialisierung ermöglicht Premium-Pricing, tiefere Kompetenz und klareres Marketing. Generalist-Positionierung ist überfüllt.
**Entschieden von**: Yahya Yildirim

---

### 2026-05 · Hybrid Production als Kernangebot
**Alternativen geprüft**: Nur klassische Fotografie / Nur KI-Generierung
**Entscheidung**: Hybrid — echtes Produkt-Foto kombiniert mit KI-Hintergründen/-Elementen
**Begründung**: Reine KI-Generierung schafft kein Vertrauen bei Produkten (Konsumenten wollen das echte Produkt sehen). Reine Fotografie ist zu langsam und teuer für Performance-Zyklen. Hybrid ist schneller als Foto allein, vertrauenswürdiger als reines KI-Output — und ab August 2026 EU AI Act-konform durch klare Kennzeichnung.
**Entschieden von**: Olha + Yahya

---

### 2026-05 · Compliance ab Tag 1 (EU AI Act)
**Alternativen geprüft**: Compliance nachträglich einbauen (ab August 2026) / Minimal-Compliance
**Entscheidung**: Volle Compliance ab Tag 1 — Trust Center, C2PA, AVV als Standard
**Begründung**: Compliance ist ein Differenzierungsmerkmal, kein Kostenfaktor. Kein anderer Wettbewerber in DACH kommuniziert das proaktiv. First-Mover-Vorteil für die nächsten 6–12 Monate.
**Entschieden von**: Yahya Yildirim

---

### 2026-05 · Frontier Firm Architektur statt klassischem Agentur-Setup
**Alternativen geprüft**: Klassisches Agentur-Setup (Projektmanagement-Tool + E-Mail + Ablage)
**Entscheidung**: Frontier Firm — Perplexity Spaces als Intelligence-Betriebssystem, Claude Code + GCP für Web, MCP-Konnektoren für Automatisierung
**Begründung**: Mirrou ist eine kleine Einheit (4 Personen). Nur durch KI-Orchestrierung kann sie wie ein größeres Studio operieren. Das ist gleichzeitig der Beweis des Konzepts für die Abschlussarbeit: Wir zeigen nicht nur, was Mirrou ist — wir zeigen wie es gebaut wurde.
**Entschieden von**: Yahya Yildirim

---

### 2026-05 · Website: Next.js + GCP statt Website-Builder
**Alternativen geprüft**: Webflow / Squarespace / WordPress
**Entscheidung**: Next.js 14 + TypeScript + Tailwind CSS + GCP Cloud Run
**Begründung**: Volle Kontrolle über Code und Design. Mehrsprachigkeit (8 Sprachen) mit next-intl. EU-Hosting (europe-west3). Skalierbar. Passt zur Frontier Firm Positionierung — eine Agentur, die ihre eigene Website selbst baut, demonstriert Kompetenz. Kein Lock-in bei einem Website-Builder.
**Entschieden von**: Yahya Yildirim (mit Claude Code als Umsetzungspartner)

---

### 2026-05 · Perplexity als primäres Intelligence-System
**Alternativen geprüft**: Notion + ChatGPT / Confluence / Obsidian
**Entscheidung**: Perplexity Spaces als Single Source of Truth für alle Wissensbereiche
**Begründung**: Perplexity kombiniert kuratiertes Wissen (hochgeladene Dokumente) mit Echtzeit-Web-Recherche in einem System. Spaces ermöglichen Bereichstrennung (Brand / Strategy / Ops / Project). MCP-Anbindung macht es erweiterbar. Kein anderes Tool bietet diese Kombination.
**Entschieden von**: Yahya Yildirim

---

### 2026-05 · Dark Luxury als visuelles Positionierungssystem
**Alternativen geprüft**: Helles, minimalistisches Design (wie viele Beauty-Studios) / Corporate Blue/Grey
**Entscheidung**: Deep Onyx (#0A0A0A) + Gold (#C9A84C) · Algorithm of Soul
**Begründung**: Der DACH-Beauty-Studio-Markt ist dominiert von weißen/beigen, hell-minimalistischen Designs. Dark Luxury fällt im Feed auf. Gold kommuniziert Premium ohne Aggressivität. „Algorithm of Soul" verbindet Technologie mit Emotion — genau die Mirrou-Positionierung.
**Entschieden von**: Olha Yevtushenko + Yahya Yildirim

---

### 2026-05 · 4-Space-Architektur für das Team
**Alternativen geprüft**: Ein gemeinsamer Space / Space pro Person
**Entscheidung**: 4 funktionale Team-Spaces + 1 privater Space (Yahya)
**Begründung**: Ein Space wird überladen und verliert Fokus. Space pro Person verhindert Team-Wissen. 4 funktionale Spaces (HQ / Strategy / Ops / Project) spiegeln echte Arbeitsdomänen — jeder Space hat eine klare Persona und klare Grenzen. Private Projekte (Opus Magnum, LYGOX, Columna) bleiben vollständig getrennt.
**Entschieden von**: Yahya Yildirim
